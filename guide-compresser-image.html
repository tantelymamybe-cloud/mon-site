Compresser une image sans perdre la qualité

Les photos prises avec un smartphone moderne pèsent souvent plusieurs mégaoctets. C'est trop lourd pour un email, un site web ou une pièce jointe administrative qui impose une limite de taille. Compresser une image consiste à réduire son poids tout en gardant une qualité visuelle correcte.

Comment ça marche

La compression « JPEG » supprime les détails que l'œil humain remarque le moins. En réglant le curseur de qualité, vous décidez du compromis entre légèreté et netteté. À 80 %, la différence est presque invisible mais le fichier est déjà bien plus léger.

Quel réglage choisir

  • 90–100 % : qualité maximale, idéal pour l'impression.
  • 70–85 % : le meilleur équilibre pour le web et les emails. C'est le réglage recommandé.
  • 40–60 % : fichier très léger, parfait quand le poids compte plus que les détails (vignettes, aperçus).

Notre outil affiche en direct le poids d'origine, le poids final et le pourcentage gagné, pour que vous trouviez facilement le bon réglage.
